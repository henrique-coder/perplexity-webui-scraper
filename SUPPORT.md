# Support

Use the right channel so the project stays maintainable.

## Questions and Usage Help

Use GitHub Discussions for setup questions, usage help, ideas, and examples that are not confirmed bugs.

## Bugs

Open a bug report when behavior is reproducible and appears to be caused by this project. Include:

- Package version.
- Python version.
- Operating system.
- Minimal code or CLI command.
- Full traceback with secrets removed.

## Feature Requests

Open a feature request when the change would be useful to more users than your specific project.

## Security

Do not report vulnerabilities publicly. Follow `SECURITY.md`.
